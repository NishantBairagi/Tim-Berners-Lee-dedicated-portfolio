About the Legend

Sir Tim Berners-Lee is a British computer scientist who invented the World Wide Web in 1989 while working at CERN. His revolutionary idea made it possible to access and share information through websites connected by hyperlinks. By making the Web freely available, he helped create an open platform that developers, students, businesses, and billions of people use every day.

His Greatest Contributions

🌐 World Wide Web

Invented the Web in 1989, changing the way people access and share information globally.

🧱 HTML

Developed the original HTML language, which provides the basic structure of web pages.

🔗 HTTP & URLs

Created foundational Web technologies that help browsers locate and communicate with resources.

💡 An Open Web

Made the Web freely available without patent royalties, encouraging innovation and development.

A Journey That Changed History

1989 — The Big Idea

Proposed a system for sharing information across computer networks at CERN.

1990 — The First Website

Developed the first web browser, web server, and the foundations of HTML and HTTP.

1991 — The Web Goes Public

The first website became publicly accessible outside CERN.

1993 — A Free Web

CERN made the Web software available royalty-free, helping the Web grow worldwide.

2004 — Knighted

Received a knighthood in recognition of his pioneering work in developing the Web.
